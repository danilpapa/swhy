## Провалы
- №15: ТЗ (E1, «Эталон истории методов», п.3) требует ручной проверки каждого коммита из объединения кандидатов. Фактически: объединение — 9152 коммита (`metrics.candidates_union`), в эталоне записаны 374 изменяющих и 0 проверенных неизменяющих (`reviewed_not_changing` = 0, `not_changing` = [] во всех 50 файлах); коммиты без изменения текста и пути метода отсеиваются кодом trace.rs:683-700; единственный разметчик — `agent:claude-fable-5-2` во всех 50 файлах. Отклонение ADR-11/ADR-12, ТЗ не разрешает.
- №18: ТЗ (E1, «Эталон истории методов», п.6) требует, чтобы второй разметчик проверил 30% методов и была посчитана каппа Коэна. Фактически: в eval/oracle/second/ только README.md, `metrics.second_annotator.methods` = 0, каппа = null (eval/results/E1-2026-11-16.json).
